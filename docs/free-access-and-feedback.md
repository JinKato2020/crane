# 無料公開とご意見受付

2026-11-01のユーザー依頼に基づく実装。まだ配信・ビルドは実施していない。

## 今回の動作

- この変更を含むバージョンから、教材・模試12回・用語・相関図をすべて無料にする。新規インストールだけでなく、このバージョンへ更新した利用者も対象。
- 評価・メール送信の有無や内容は無料利用の条件にしない。既存の購入済み権利も残す。
- 無料利用権を端末に保持する。再インストール・機種変更では、署名検証済みの `AppTransaction.originalPurchaseDate` で対象者を復元する。同じApple Accountでの取得が前提。復元にはApp Storeとの通信が必要になる場合がある。
- 初回利用から4日以上経過し、教材・用語または模試を利用した人がホームに戻ったとき、標準のApp Store評価APIを呼ぶ。次回はその依頼から4日以上後。アプリを使っていない間に通知・メールを送ることはない。
- 同じタイミングでホームにご意見カードを表示する。閉じられ、設定からも随時開ける。メール宛先は `contact@safa-lang.com`。端末のメール作成画面で本人が送信する。メールアプリが使えないときは宛先をコピーできる。
- 評価ダイアログの実表示はAppleが制御する。4日ごとの表示は保証しない。旧来の模試1回・7回完了時の評価依頼は廃止。

## 将来、無料公開を終了するとき

評価の平均値を取得して自動で課金に切り替える実装はしていない。運営者が時期を決め、新バージョンで切り替える。

1. `PromotionPolicy.enrollmentOpen` を `false` にする。
2. `PromotionPolicy.enrollmentEndsAt` に実際の募集終了日時をUTCで設定する。`nil` のまま終了すると、端末に権利が残らない利用者の再インストール時に復元できないので、必ず日時を設定する。
3. 公開終了時刻より前の初回取得者は、その後も無料。終了時刻以降の新規取得者だけが従来の無料範囲とPro買い切りの対象になる。
4. 今回の無料公開版を起動して付与済みの権利も、後のアップデートで削除しない。

本設定はアプリに同梱する。過去の無料公開版自体の挙動を遠隔で切り替える機能はない。旧版を使う人の無料利用は継続する。

## 確認

- 設定の購入・利用権復元の下に通常利用向けの「アプリを評価する」を配置。Appleの公開lookupでbundle ID `com.safa.crane` に対応するID `6818800945`を確認し、`action=write-review`付きのApp Storeリンクを開く。標準評価ダイアログの表示制限とは独立した、本人操作によるレビュー画面へのリンク。
- 設定の「開発用・表示確認」に評価APIとリクエスト画面の手動トリガーを用意。Debug／sandbox receiptのあるTestFlightで表示。それ以外でも設定のバージョン欄を7回タップすると、その画面で開発用項目を表示できる。
- 手動トリガーは4日の通常スケジュールを変更しない。評価APIを呼び出したことを画面に表示する。Appleの制約によりTestFlightでは評価ダイアログは表示されず、Xcodeの開発ビルドで確認する。リクエスト画面はTestFlightでも開ける。
- `tools/verify_promotion.swift` は実際の判定関数を使い、募集終了境界、4日間隔、未学習、時計が戻った場合を検証する。既存CIの事前検証へ追加。
- Windows作業環境にはSwift/iOS SDKがないため、Swift検証・iOS実機のメール送信・Apple署名情報による復元は未実行。次回のビルドと実機確認が必要。

参照：[Appleの評価依頼仕様](https://developer.apple.com/documentation/storekit/requesting-app-store-reviews)、[AppTransactionによるビジネスモデル変更](https://developer.apple.com/documentation/storekit/supporting-business-model-changes-by-using-the-app-transaction)。
