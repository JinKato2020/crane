ホームとヒーローの更新方法

2026年11月6日。今回の対応版をインストールした後は、画像と候補一覧をOTAで更新できます。画面構造やアプリの挙動を変更するときは新しいビルドが必要です。

ユーザーができること

  • ホームの「背景を選ぶ」または設定の「ホームの背景」から変更。プレビュー後、「この背景にする」で保存。×で閉じた場合は変更しません。
  • 既存画像を既定に、アニメ調・工場内・追加5枚、計8枚を収録。「画像なし」も選べます。前回却下された実写の朝景色・シンプル図は含みません。
  • 選択は端末に保存。画像の選択とライト／ダークは独立。新しい候補を受け取っても、既存の選択を勝手に変更しません。
  • 選択した候補が配信一覧から削除された場合は、その一覧の既定画像で表示。壊れた一覧・通信失敗時は同梱一覧、壊れた画像は元のHero画像へフォールバックします。

画像を追加・差し替える

CraneExam/Resources/home_heroes.jsonが候補一覧です。画像はResources/images/home_hero_*に配置します。管理コマンドは画像を変更せずコピーし、ファイル名に内容のハッシュを付け、manifestを再生成します。

python tools/manage_home_heroes.py list

# 新しいIDなら追加。同じIDなら画像・表示名を差し替え
python tools/manage_home_heroes.py set --id harbor-night --title "夜の港" --subtitle "実写調" --image "C:/path/to/image.png"

# 選択肢の並び順（現在のIDをすべて1回ずつ指定）
python tools/manage_home_heroes.py order existing anime cinematic 01-cabin-twilight 02-rain-harbor 03-first-light 04-skyward 05-homeward harbor-night

# 未選択ユーザーの既定画像
python tools/manage_home_heroes.py default existing

# 一覧から外す。旧画像ファイルは既存キャッシュのため保持
python tools/manage_home_heroes.py remove harbor-night

python tools/verify_home_heroes.py

コミット・Push後、既存の deploy-content-crane.yml を実行して配信します。ResourcesとドキュメントだけのPushはiOSビルドを起動しません。今回の土台版が入っている端末は起動時、復帰時、設定の「教材・画像を更新」から取り込みます。古いアプリにヒーロー選択画面をOTAだけで追加することはできません。

同じ候補を差し替えるときは id を維持してください。新しい別候補には新しいidを付けます。画像は先に取得し、取得に失敗した場合は新しい一覧への切り替えを保留します。

ホーム・学習記録

  • 学習再開を上部に配置。教材は前回の節、用語は前回の章から開きます。模試は「模試を開く」としてタブへ戻ります。中断した模試の解答を新たに永続化する機能ではありません。
  • 教材・用語・模試を30秒以上アクティブ表示して離れたとき、種類別に端末へ記録。週の学習日は重複させず、既存の模試解答日も含めます。学習の記録を理解度・合格保証と表現しません。
  • 成績の詳細はホームの専用入口から確認できます。お気に入り・ブックマーク・相関図・総合解説も保持しています。

無料キャンペーンと評価

  • 無料利用権があるユーザーに、最初の案内を表示。閉じるか学習を開始したら再表示しません。既存の購入済み権利・無料付与の条件は変更していません。
  • 利用3日目以降、30秒以上の学習を終えたときに評価APIを呼びます。次回は7暦日以上後。約2秒の遷移待ちの間に新しい学習やタップが始まった場合、別のシート表示中、非アクティブ時は見送ります。
  • Apple標準の評価画面を使用。別の評価ポップアップや「満足した人だけApp Storeへ」の分岐は設けません。表示・評価送信・星数はアプリ側で取得できません。
  • 設定の利用権復元の下に、App Storeのレビュー直リンクとご意見の入口を常設。同時にリクエストカードを自動表示する旧処理は撤去。無料利用は評価・メール送信の有無に関係なく継続します。
