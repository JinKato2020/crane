第1章「クレーンに関する知識」
精密レビュー

基礎を学ぶ土台は十分。ただし、現状を「この章だけで本番対策が完成」とは評価しません。

題材の広さと、日常のイメージで説明する方針はよい状態です。改善の中心は図の追加枚数ではなく、部品の誤認を防ぐ修正、出題される細部の補充、図と本文の一致、通常表示での読みやすさです。

何を、どこまで確認したか

現行アプリの第1章は、配信中の教材データと一致しました。節番号は現在アプリに表示される順番です。保存用IDとは順番が異なるため、以下では併記しています。

対象実施した確認範囲・限界
現行教材16節・504ブロックを通読。本文338段落、図68点、表1個。用語、数値、説明順、重複、図と本文の対応を確認。
指定書籍第1章の抽出テキストを通読し、疑義・図形・OCR不足箇所を原本で確認。原本75ページのうち12ページを拡大目視：印刷頁9,33,36,44,45,49,55,73,74,77,78,81。

公表問題安全衛生技術試験協会の令和8年4月・10月、各問1～10の本文と全選択肢を確認。20問・100選択肢。全年度の出題頻度や合格率を測ったものではない。

判定はユーザー指定書籍の試験上の整理を基準にしました。一般論や機械の例外を理由に、指定書籍の正答を否定する判定はしていません。

評価の要点

観点評価理由
本番に必要な情報主要範囲は広いが、補強が必要部品識別・調整箇所・操作のタイミングなど、選択肢を決める細部が一部欠ける。
初学者への分かりやすさ入口は良好。基本と例外の順序に課題力の流れ、地切り、停電時の制動などの理由は分かる。注意書きが基本事項を覆う箇所がある。
見やすさ本文は読める。図の主要文字と比較配置を改善本文16pt・行間がある一方、図中文字の縮小が大きく、表が1個しかない。
図と解説のバランス量は足りる。役割と位置を整える段階68図ある。図を増やすより、同じ例・同じ部品・同じ説明箇所に対応させることが優先。
試験直前の復習改善余地が大きい重要数字・対比・図形識別の一覧と、章末の確認問題が弱い。

優先順位付きの指摘

「先に直す」は誤認・得点への影響・通常表示の可読性を優先したものです。A・B・Cは重大さの厳密な点数ではありません。

A01 · 先に直す · 図の誤認

ばねナットの形が指定書籍と異なる

8節 歯車・軸・軸受・ボルト｜1-9 / block 46

教材の3D図は、ねじ穴のある折り曲げた板・クリップ状の部品を描いている。指定書籍は、ばね鋼を2～3巻きし、六角ナットの上に取り付ける部品を示している。単なる画風の違いではなく、形を覚えて解く問題に影響する。

修正案
指定書籍の形を基準に、単体と取り付け状態の2図で描き直す。皿ばね座金などの比較は残し、どこを見ると見分けられるかを一行で添える。

根拠・追跡先：指定書籍 p.55、令和8年4月・10月公表 問4。画像：1-9_supplement_f17_20261023.png

A02 · 先に直す · 出題事項の不足

バンドブレーキの調整用ボルトが説明されていない

13節 ブレーキ｜1-11 / blocks 14–16

帯で締める原理は説明できているが、指定書籍の「緩めたときに均等に離れるようにする調整用ボルト」の役割がない。掲載3D図にも、その識別につながる注記がない。

修正案
調整用ボルトを指す短い注記を追加し、「締めて止める」「緩めて均等に離す」を対にする。部品名を取り違えさせる選択肢を一問添える。

根拠・追跡先：指定書籍 p.73、令和8年4月 問2・10月 問6

A03 · 先に直す · 出題事項の不足

停止時の追いノッチのタイミングが不足

14節 安全運転｜1-14 / blocks 27–30

発進時の考え方とインチングはあるが、停止時の追いノッチの手順がない。荷が振り切れた後に操作する説明を見抜くための知識が不足する。発進図も最終コマでロープが傾き、振れを抑えた結果が読み取りにくい。

修正案
指定書籍に沿って発進時と停止時を別々の3コマで示す。停止時は荷が前へ振り切れる前の短い再操作を明確にし、台車の移動方向・荷の移動方向・操作の入切をそろえる。

根拠・追跡先：指定書籍 pp.77–78、令和8年4月・10月 問10

A04 · 先に直す · 試験向けの説明順

指定書籍で覚える基本事項より、例外や注意が強く見える

6節 骨組み／8節 歯車｜1-5 / blocks 25–35、1-9 / block 16

揺脚について「垂直荷重しか受けない」と無条件に考えないよう促す一方、指定書籍の試験上の整理を先に明示していない。はすば歯車も、平歯車より大きな減速比にできるという書籍の特徴が薄れ、歯数比の注意が前に出る。ホイストも同様に、横行装置との一体化より例外が印象に残る。

修正案
指定書籍の基本形・正答になる整理を、本文の最初に短く提示する。詳細な実機の例外は必要なものだけ補足へ移す。書籍の答えを否定する評価にはしない。

根拠・追跡先：指定書籍 pp.33、36、49。給脂周期は15節に代表値の表があり、その構成は生かせる

A05 · 先に直す · 図と本文の不一致

2段減速の図は9、直後の本文は40

8節 歯車・軸・軸受・ボルト｜1-9 / blocks 10–13

図は20歯→60歯を2段つなぐ例で減速比9。本文は8歯→64歯と30歯→150歯で減速比40。個々の計算は正しいが、一つの例を図で追う読み方ができない。

修正案
歯数・A～D・回転数を図と本文で統一する。その後に別問として、中間軸の回転数から入力側と出力側の両方を求める練習を追加する。

根拠・追跡先：教材PDF p.30にも同じ不一致。令和8年4月 問7は中間軸から考える問題

A06 · 先に直す · 概念図の不足

基本運動の図に巻上げ・巻下げの矢印がない

3節 全体の形と動き｜1-3 / block 4

本文は基本運動を扱うが、図は「4運動」として走行・横行・起伏・旋回を示し、上下方向が抜けている。図のキャプションには巻上げが含まれているため、対応もそろわない。

修正案
巻上げ・巻下げを一組の上下矢印で追加し、5種類の基本運動として整理する。天井クレーンとジブクレーンの持つ運動を区別する。

根拠・追跡先：1-3.svg、本文と図の照合

A07 · 先に直す · 図の可読性

通常表示で主要ラベルが約7～8px相当になる図がある

主に8節・13節ほか｜複数図

スマホ幅390px、本文幅約350pxで縮小すると、1440幅の図内30px文字は約7.3px、2000幅の図内40px文字は約7pxとなる。本文16ptに対し差が大きく、拡大前に図の要点を拾いにくい。

修正案
部品名・動き・結論は通常表示でも読める大きさを目標にする。横4列を2×2へ、図中文字を減らして主要説明を本文へ。重要ラベルは表示時12～14程度を設計目安にし、細部はタップ拡大に残す。全ての文字を一律に巨大化しない。

根拠・追跡先：TextbookView.swift、SVGのviewBox/font-size、390px幅の再現表示。iOS実機の測定値ではない

B01 · 次に改善 · 参照の不整合

図にない「図の9.5t」を本文が参照する

4節 基本用語｜1-2 / blocks 6–9

別の数値例として10.0−0.5＝9.5tを説明した後で、「図の9.5t」と呼んでいる。現在の図にはその数値がない。単位や荷の範囲の注意も連続し、最初の区別が埋もれる。

修正案
図に同じ数値を載せるか「上の例の9.5t」に統一する。基本の引き算をまず一例で完結させ、補足はまとめる。

根拠・追跡先：1-2_lifting_load.svg と本文

B02 · 次に改善 · 概念と応用の順序

傾斜角の基準線が弱く、cosの例には対応図がない

4節 基本用語｜1-2 / blocks 24–33

3D図は姿勢の違いを伝えるが、水平を基準に角を測ることを角度弧と基準線で示していない。続く2m＋10m×cos60°の計算には、その2mや直角三角形を示す図がない。

修正案
3D図に水平線と角度弧を添える。数式は「応用」に分け、残すなら数値入りの小さな平面図を付ける。確認した公表20問にcos計算はなかったが、それだけで出題されないとは断定しない。

根拠・追跡先：1-2_jib_radius.svg、本文

修正案

根拠・追跡先：図番号13・15（figures.json参照）、本文と指定書籍の種類説明

B05 · 次に改善 · 説明順

B06 · 次に改善 · 図の位置

B07 · 次に改善 · 比較のしやすさ

B08 · 次に改善 · 重複の整理

8節 / 1-9歯車・軸・軸受・ボルト――回転を伝えて支える部品（図13点）歯数比の説明、ボルトの力の伝え方が丁寧ばねナット、計算例の不一致を先に修正。長い節を小まとまりに整理。A01・A04・A05・A07・C01
9節 / 1-13ドラムとシーブ――巻き取る円筒と、案内する滑車（図2点）ドラム・シーブ・捨巻・D/dを扱っている3テーマをまとめた図の位置とキャプションを調整。B06
10節 / 1-7ワイヤロープ――細い鋼線を二段階でより合わせる（図5点）構成・より方・測径・末端処理を一通り学べる末端5方式の比較表と、通常表示で読めるラベルへ。B07・A07
11節 / 1-8荷をつかむつり具――荷の形や材質に合わせる（図4点）荷の材質や形と、つり具の役割が結び付くグラブ・スプレッダの重複を統合。仕組みを見たい箇所だけ拡大。B08
12節 / 1-10安全装置――どんな危険を防ぐのか（図6点）装置ごとに何の危険を防ぐかを説明できている直働／間接、アンカー／レールクランプ、車輪止めの数値を比較できる形へ。B10
13節 / 1-11ブレーキ――止める働きと、保持する働き（図5点）保持の理由、停電時の動き、1.5倍の対象は分かるバンドの調整用ボルト、形と作動方式の二つの分類を先に整理。A02・A07・B08
14節 / 1-14安全運転――荷を上げる前に問題を見つける（図3点）地切りや重心、運転者の位置の理由が理解しやすい停止時追いノッチを追加し、重複と慣性図の配置を整理。A03・B08
15節 / 1-12給油と点検――動き続けるために状態を保つ（図3点）白濁、供給確認、給脂周期の表はよい密閉減速機の油交換を明記。重複を減らし第2章へ案内。B09・B08・C02

読みやすくする改訂の型

同じ内容を文章・図内長文・囲みで三度説明しない構成にします。各小テーマを「一言の結論 → なぜそうなるか → 見るべき場所が分かる図 → 試験の見分け方 → 短い確認」の順に統一すると、初学者にも復習にも使えます。

例：バンドブレーキ

帯を締めると、回転が止まる。
ドラムのまわりの帯が、摩擦で回転を止めます。

［3D図：ドラム・帯・調整用ボルトの3か所を示す］

調整用ボルト：ブレーキを緩めたとき、帯がドラムから均等に離れるように調整します。

確認：「摩擦パッドで、締めるときのすき間を調整する」は正しい？
答えを表示 → 誤り。部品は調整用ボルト、着目するのは緩めたとき。

技術図の3D表現は維持します。機構の細部を見せる図と、動き・理由を理解する模式図を使い分けます。色は力・運動・注目箇所などの役割に固定し、色数や装飾を増やすことを目的にしません。
