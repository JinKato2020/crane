# 模試と教材の参照・記載不足の修正

全12回480問の監査で、別の論点へ移動する参照、表・箇条書きでは解決できないアンカー、正解の根拠の説明不足が見つかった。第1回問22は「周波数」へ移動していたが、今回から「整流・脈流・平滑」を直接表示し、巻数比・実効値・三相・周波数も個別に確認できる。

## 変更

- 全480問の教材参照を見直し、696件の固定ブロックIDによる参照を設定。複数の根拠がある問題は個別リンクを表示する。
- `Question.refs`を追加し、模試画面・問題詳細の両方で選択した参照を開く。旧`ref`も残し、旧データは1件の参照として動く。
- 教材全ブロックに固定IDを付与。今後、文言・順序を変えてもIDを維持する。
- 参照解決は固定IDを最優先。旧アンカーは小見出し→本文・表の見出し・セル・箇条書き・図のキャプションの順で扱う。見つからなければ節全体を表示して明示する。
- 第2章の検査・点検は年次・月次・開始前・暴風地震後の見出しを作り、長い表の文章を省略せず分割した。
- 主根拠不足60問・補足推奨20問の論点を36項目へまとめて追記。円運動と質量分布の対称性も補足した。新しい語句も暗記クイズに対応する。
- 第1回問6・問10、第2回問18の選択肢先頭に混入した問題文を本文へ戻した。5択にすると、元の1始まりの正解番号が解説の組合せ（C,D／A,D／C,D）と一致する。正解番号自体は変えていない。
- 図、用語集、全問の正解番号と解説、残り477問の問題文・選択肢は保持した。

## 検証

`python tools/verify_textbook_links.py`で以下を確認する。

- 12回×40問、各科目10問、全問5択、正解番号の範囲。
- 696参照のIDの実在・重複なし・旧refとrefs先頭の一致。
- 監査で指定した80問すべてが追記項目へ参照できること。
- 代表的な誤参照の正しい参照節と、3問の表示上の正解。
- 追記例題の19計算を独立に検算。
- ローカルの変更前バックアップがあるとき、図・用語集・問題データの保持も比較する。

CIのビルド前には、同じPython検証に加え、`Models.swift`と`Textbook.swift`を実際にコンパイルする`tools/verify_reference_resolver.swift`を実行する。アプリと同じ解決関数で全参照の解決、固定ID優先、旧形式の表・箇条書き検索、空refsからの旧refへのフォールバック、不存在時のnilを確認する。**ローカルWindowsではSwiftコンパイラがないため、このSwift検証とiOSコンパイルの完了をローカル実施済みとは扱わない。**

教材のHTML見本は320px／390pxで全41節に横はみ出しがないことを確認し、整流・鉛直加速・点検の3箇所を目視した。これはiOS実機確認ではない。

## 教材追記の根拠

既存の模試解説・教材の基礎をつなぐ独自の説明。法令の新たな解釈変更や公式書籍の正答を否定する変更はしていない。電気の保護・測定手順の説明は、次のメーカー資料でも確認した。

- [オムロン：サーマルリレー](https://www.fa.omron.co.jp/guide/glossary/meaning/3849.html)（バイメタル・接触器との役割分担）
- [オムロン：低圧開閉器の技術資料](https://www.fa.omron.co.jp/data_pdf/commentary/lowvoltageswitchinggears_tg_j_2_1.pdf)（短絡保護との分担）
- [HIOKI GENNECT：絶縁抵抗の測定方法](https://www.gennect.net/ja/knowledge/fmi/ir-measurement)（停電・切離し・測定後の放電）
- [日立：低圧開閉器の技術資料](https://www.hitachi-hitt.com/catalog_sw/catalog/SI-501R.pdf)（スターデルタ始動の巻線電圧）

## 運用

`tools/link_repair/plan.json`は修正前の全480問の監査対応表。`lessons.py`は共有する追記本文、`repair_textbook_links.py`は一度だけ適用する反映スクリプト。教材と模試は変更前に同階層の`.bak_pre_link_repair_*`へバックアップした。

同梱manifestを再生成して新しい教材・模試の指紋へ更新する。古い配信データへの巻戻りは既存のContentOTAの生成日時判定で防ぐ。今回の依頼ではOTA配信は行わず、新ビルドへ同梱する。

ビルド番号の下限を2034へ更新する。ユーザーの厳格な指示に従い、コミット・Pushでビルドを開始した後、実行一覧・ジョブ状態・完了結果は照会しない。
