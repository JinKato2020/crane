# 用語集の技術図4点の修正

ユーザー指摘：歯車の回転矢印、ボルト継手の矢印の可読性、普通より・ラングより及びすて巻の3D規格。

## 確認した問題

- `1-9_gears_readable21.png`：平歯車・はすば歯車の上下が同じ向きに回る矢印。外歯車の回転関係と不一致。ウォームの直線矢印も回転と軸方向移動を混同させる。
- `1-9_bolts_readable21.png`：細い赤矢印が金属の上に重なり、縮小時に読み取りにくい。
- `1-7_wire_lay_readable21.png`：用語集は旧図を参照。教材本文には別名の新しい3D比較図があり、更新がそろっていなかった。
- `1-6_drum_equalizer_readable21.png`：既存の平面的な構造図が残存。過去の作業記録では、新しい生成候補のロープ経路に不整合があり不採用としていた。

## 差し替え内容

- 歯車：上を時計回り、下を反時計回りの矢印に訂正。かさ歯車・ウォームの種類説明には回転矢印を付けず、軸の位置関係を示す。
- ボルト継手：赤矢印を太くして白縁を付ける。各板の横方向荷重とボルトの引張りを見分けやすくする。
- 普通より・ラングより：金属の立体描写と、より方向が反対／同じになるストランドの拡大比較。生成初稿で拡大ストランドが同じ向きだったため修正案を採用。
- ドラム：すて巻の2巻を強調し、払い出すロープとの連続性を明示。エコライザシーブは外周にロープを掛ける。D/dは寸法を読む部分のみ平面図にする。

組込みの `image_gen` で生成・編集。プロンプトは同名の `-prompts.json` と `-corrections.json` に保存。PNG4点及び対応するSVG3点に同じ採用画像を使う。SVGはPNGをそのまま内包し、画像の加工は行わない。

元画像7点と採用元の対応は、アプリのバンドル対象外にある `教材画像/用語図修正_20261031/` へ保存。教材の本文・用語定義・模試は変更しない。

参照根拠：公式OCR `テキスト/書籍1.txt` の普通より・ラングより、すて巻、エコライザシーブ。外歯車の回転関係は [小原歯車工業](https://www.khkgears.co.jp/gear_technology/basic_guide/khk351_2/)、より方の定義は [厚生労働省資料](https://www.mhlw.go.jp/content/11300000/001513163.pdf) とも照合。

検証済み：採用画像の目視、画像4枚の読み込み、SVG3枚の内包PNGが用語集PNGとバイト単位で一致、マニフェスト513件のサイズ・ハッシュ一致、390px幅のHTMLプレビューで横はみ出しなし、`git diff --check`。教材参照検証も480問・696参照で通過。iOS実機での表示確認は未実施。
