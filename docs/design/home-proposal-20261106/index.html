クレーン試験対策 · ホーム画面の提案

好きな景色で、今日の一歩を。

学習への入口はひとつに。ヒーローは、好みに合わせて。

提案用モックアップ・未実装

既存のヒーローを初期設定に。アニメ調・新作のシネマ調も選べます。
教材の図は共通の規格を維持。着せ替えはホームのヒーローだけに限定します。

数値・学習履歴は提案用サンプルです。
SwiftUIの実機スクリーンショットではありません。

レビューと提案の意図

現行のHomeView・Theme・学習記録のコードと、現在のヒーロー画像を確認しました。今回はアプリのコード・既存画像・教材データを変更せず、画面案を作成しています。

まず、学習を始めやすくする

現在はヒーローの下に評価の案内、試験日、分野別の実力が続き、教材へ進むカードが下へ押し出されています。新案は「つづきから学ぶ」を最初の画面内に配置。初回は「学習をはじめる」、中断後は前回の教材・用語・模試の続きへ進む一つの主ボタンにします。試験日は上部の小さな表示にし、未設定なら「試験日を設定」と表示します。

模試を受けない人にも、学んだ実感を

現在の継続記録は模試の解答数が対象です。教材・用語・模試を各30秒以上表示し、その学習画面を離れた際に記録する方針を提案します。同日に何度学んでも学習日数は1日。読んだ時間を理解度や合格可能性に置き換えず、学習した事実を記録します。

「弱点あり」をホームの最上段に出す構成から、今週学んだ日を穏やかに振り返る構成へ。休んだ日も過去の積み重ねが消えない週単位の表示にし、詳しい正答率・弱点分析は「模試・成績」で確認できるようにします。評価・リクエストの表示時期は維持し、学習の主ボタンを押し下げない位置に置きます。

写真とアニメを、好みで選べる

既存のヒーロー画像「いつもの景色」、落ち着いたアニメ調「未来の自分」、新作のシネマ調「仕事の余韻」の3案。前回の1枚目（現場の朝）と3枚目（静かな集中）は候補から外しました。新作は工場の床から天井クレーンを斜めに見上げ、夕方の光で静かな仕事の余韻を表しています。画像なしも選べます。画像の自動変更はせず、選択を保存。ライト／ダークと画像の種類は独立させます。文字は画像に焼き込まず、UIで表示するため読みやすさや文字サイズに対応できます。

情報の強弱と文字サイズ

ゴールドは主ボタン、紺は見出し、落ち着いた青緑は学習記録に役割を分けます。4つの主要入口の下に、お気に入り・ブックマーク・総合解説を整理。通常サイズで主ボタン16pt、見出し18〜23ptを想定し、実装ではDynamic Type・VoiceOver・タップ領域を確認します。

提案を操作する

各画面の「背景を選ぶ」で、選択画面の動きを試せます。学習開始ボタンや教材へのリンクは、提案段階のため動作しません。

確認後に必要な実装

ホームの再構成、学習を再開する位置の保存、教材・用語を含む学習日の記録、背景の選択保存が必要です。画面案の確認後に着手します。現在の学習・模試・教材の挙動は変更していません。
