# 教材OTAの更新反映修正（2026-10-23）

## 確認した事実

- 公開配信先のmanifest、教材JSON、追加58画像のSHA-256・サイズはローカルと一致。配信ファイルの欠落はない。
- 端末では以前の教材・図が表示されるとの報告。端末ログは未取得のため、個別端末の失敗理由は未確定。
- 既存コードは起動時だけ同期し、章画面は遷移時の教材データを保持していた。通信失敗も画面に出なかった。

## 変更

- アプリがアクティブになった際にも更新を確認。多重実行と成功後60秒以内の自動再確認を抑制。
- 設定に「教材・画像を更新」、取得件数、通信・保存失敗のメッセージを追加。
- 章・節画面はストア内の最新章を参照し、取得した画像も更新後に再読込。
- キャッシュのSHA記録だけ残り実ファイルがない場合は再取得。
- 取得ファイルのSHA-256とサイズを照合。画像を先に取得し、失敗時は教材JSONの切替を保留。
- ダウンロードの待ち時間を延長し、キャッシュ台帳の保存失敗を通知。

## 検証と制限

- 公開先の教材と追加58画像の照合は成功。
- `git diff --check` 成功。呼出元と教材モデルの整合をコードレビュー。
- Windows環境にSwift/Xcodeがないため、SwiftコンパイルとiPhoneでの動作確認は未実施。
- 既存の「ビルド不要」の指示に従い、ビルド番号は2029のまま。ビルド・TestFlight配信は実行していない。
- この修正はアプリコードの変更であり、教材OTAだけでは既存バイナリに適用できない。

## 次の実機確認

1. 古い教材を開いたまま更新し、現在の章と新しい図が切り替わること。
2. バックグラウンドから復帰して更新を確認すること。
3. オフラインで失敗表示が出て、再接続後に手動更新できること。
4. 画像の一部取得失敗時には新教材への切替を保留し、再試行で不足分を取得すること。
5. 記録済みのキャッシュ画像を失った状態で再取得すること。
